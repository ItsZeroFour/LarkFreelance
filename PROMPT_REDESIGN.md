> Два промпта: **A** — для Claude Design (дизайн), **B** — для Claude Code (имплементация).
> Проект: `lark_web-main` — Next.js 14 / React 18 / TS / Tailwind 3.4 / framer-motion 11.

---

## ПРОМПТ A — для Claude Design

Скопировать целиком, подставив название дизайн-системы в первой строке.

---

Работаем с дизайн-системой **«<НАЗВАНИЕ ДС>»** — она уже готова в этом проекте. Её токены, примитивы и правила — единственный источник истины; ничего не изобретаем поверх.

**Задача:** переложить работающий сайт **Lark Freelance** на эту дизайн-систему. Контент, структура и логика сохраняются полностью. Меняется системный слой: токены, типографика, сетка, вертикальный ритм, состояния компонентов.

**Это не редизайн с нуля.** Формулировка задачи — «слегка переизобрести». Бюджет изменений маленький и тратится строго на системность: воздух, ритм, иерархию, типографику. Не на новые концепции.

### Главное ограничение: минимализм — это ДНК, а не стиль

Текущий сайт держится на минимализме, и это его сильная сторона. Новая версия должна стать **тише, а не богаче**. Хорошая правка здесь — та, что убирает, а не добавляет.

**Запрещено добавлять:**

- маскотов, персонажей, иллюстративные метафоры — никакой птицы, руки, талисманов, нарративных сцен
- 3D-объекты, «живые орбы», neural-визуализации, WebGL, canvas-сцены
- новые декоративные слои поверх существующих (сайт уже несёт шум, свечения и сетку — их скорее нужно проредить, чем дополнить)
- сложные вводные анимации, скролл-сторителлинг, параллакс-сцены
- любые новые смысловые сущности, которых нет в текущем контенте

Если возникает выбор между «выразительнее» и «спокойнее» — выбираем спокойнее. Ощущение на выходе: дорогая сдержанность, много воздуха, безупречная типографика, ноль визуального шума ради шума.

### Что за продукт

Lark Freelance — русскоязычное IT-агентство: веб-разработка, AI-автоматизация, IT под ключ. Тон — премиальный, редакционный, спокойно-технологичный, без стартап-хайпа. Весь интерфейс на русском.

Конверсионный путь: **ценность → доказательство (кейсы) → Larkins (AI-бриф) → контакты**.

### Текущий дизайн-слой, который нужно системно заменить

- **Токены** (`src/styles/variables.css`): поверхности `--bg / --bg-secondary / --bg-tertiary / --surface`; текст `--text / --text-muted / --text-faint`; акцент `--accent / --accent-light / --accent-ink / --accent-soft`; границы `--border / --border-strong`; свечения `--warmth / --glow / --spotlight`; сетка `--grid-line`; глубина карточек `--card-top-light / --card-shadow`; кривая `--ease`
- **Типо-шкала** (`src/styles/typography.css`): `.font-display`, `.t-hero`, `.t-section`, `.t-card`, `.t-meta`, `.t-mono`, `.t-body`, `.t-lead` — всё на `clamp()`
- **Утилиты** (`globals.css`): `.shell` (контейнер 1200px + адаптивные поля), `.surface` (1px граница + внутренний хайлайт + мягкая тень), `.grid-lines`, `.dot-field`, `.hairline`, `.floating` (blur-подложка), маски `.mask-radial / .mask-t / .mask-x`
- **Примитивы**: `Button` (primary / secondary / ghost, md / lg, ссылка или кнопка), `Card` (interactive / featured + spotlight по курсору), `Section` (ритм + градиентный разделитель), `SectionHeading` (эйрбоу с живой точкой + крупный фолио-номер фоном + заголовок с акцентным `<em>` + лид), `Icon`, `Logo`, `Glow`, `GridBackdrop`, `Spotlight`, `Magnetic`, `NoiseOverlay`, `Cursor`

**Отдельно реши и зафиксируй:** какие декоративные примитивы (`Glow`, `Spotlight`, `GridBackdrop`, `NoiseOverlay`, `Cursor`, `Magnetic`) новая ДС заменяет своими, какие остаются, а какие **удаляются совсем** ради чистоты. Здесь удаление — приветствуется: это главный резерв минимализма.

### Жёсткие ограничения

1. **Кириллица обязательна** — включая курсивное начертание для акцентных слов в заголовках. Шрифт без кириллицы не рассматриваем, даже если он есть в ДС.
2. **Две темы.** Тёмная — базовая, светлая — полноценная, не остаточная. Каждый токен определён в обеих. Контраст минимум AA (4.5:1 body, 3:1 крупный текст).
3. **Mobile-first**, брейкпоинты 400 / 640 / 768 / 1024 / 1280. Горизонтальный скролл на 390px недопустим ни в одном состоянии. Тач-таргеты ≥ 44px.
4. **Доступность:** видимый focus-ring на всех интерактивных элементах, полное уважение `prefers-reduced-motion`, корректная семантика аккордеона и мобильного меню.
5. **Контент не переписываем** — тексты, цены, названия кейсов, вопросы FAQ остаются как есть.
6. **Производительность:** декоративный слой — только CSS-градиенты, маски, SVG и трансформы. Никакого видео, WebGL и canvas.

### Что должно быть на выходе

1. **Карта токенов**: старый → новый, с явной пометкой того, чему нет эквивалента, и что предлагается взамен.
2. **Типографическая шкала** под кириллицу: пары шрифтов, веса, размеры (`clamp`), интерлиньяж, трекинг — от hero до подписи.
3. **Спецификации примитивов** — кнопка, карточка, поле ввода, аккордеон, чип/бейдж, навигация, футер: состояния default / hover / active / focus-visible / disabled / loading в обеих темах.
4. **Раскладки всех секций** в трёх ширинах (390 / 768 / 1280) с реальным русским контентом, без lorem ipsum.
5. **Сетка и ритм**: контейнер, поля, шкала отступов, расстояния между секциями, способ их разделения.
6. **Правила движения**: длительности, кривые, паттерн появления при скролле, hover-отклик и их редукция при `prefers-reduced-motion`. Движения должно стать меньше, чем сейчас.
7. **Блок Larkins отдельно**: все состояния чат-брифа — пусто / печатает / история / ошибка / отправлено.
8. **Список удалённого**: что из текущего декоративного слоя уходит и почему.

Формат — отдельные превью-страницы дизайн-системы, каждая со своей карточкой в панели проекта. Не единый макет одной картинкой: нужны переиспользуемые спецификации, из которых собирается страница.

### Критерий приёмки

Разработчик открывает выдачу и без единого вопроса переписывает `variables.css` и `typography.css`, обновляет `tailwind.config.ts`, переверстывает примитивы в `src/components/ui/` и раскладывает по ним секции — получая сайт, идентичный дизайну в обеих темах и на всех брейкпоинтах.

## ПРОМПТ B — для Claude Code (имплементация)

> Перед первым запуском один раз выполнить `/design-login` в интерактивной сессии Claude Code —
> иначе доступ к проектам Claude Design из кода не работает.

---

Дизайн-система **«<НАЗВАНИЕ ДС>»** готова в Claude Design. Задача — перевести на неё сайт `lark_web-main`, не меняя контент и функциональность. Дух правки — минимализм: если что-то можно убрать, а не переделать, убираем.

Порядок работы — по слоям снизу вверх, со сборкой после каждого:

1. **Токены** — `src/styles/variables.css` под токены ДС; обе темы (`:root` = dark, `[data-theme="light"]`) заполнены полностью. Режим `[data-mode="amber"]` (пасхалка) — либо сохранить, либо осознанно удалить.
2. **Tailwind** — синхронизировать `tailwind.config.ts`: цвета, шрифты, тени, кривые, брейкпоинты.
3. **Типографика** — `src/styles/typography.css`; шрифты через `next/font/google` в `src/app/layout.tsx` с обязательным сабсетом `cyrillic`.
4. **Утилиты** — `.shell / .surface / .floating / .grid-lines / .hairline` и маски в `src/app/globals.css`.
5. **Примитивы** — `src/components/ui/`: `Button`, `Card`, `Section`, `SectionHeading`, `Icon`. Публичные пропсы не ломать — секции опираются на текущий API.
6. **Секции** — по одной: About, Services, Process, Portfolio, Team, Larkins, FAQ, Contact, Freelancers. Затем Hero, Navbar, Footer.
7. **Страницы** — `/portfolio`, `/portfolio/[slug]`, `/larkins`, `not-found`, og-картинки.

**Не трогать:**

- данные в `src/data/` — услуги, кейсы, команда, процесс, FAQ, контакты
- JSON-LD (`ProfessionalService` в layout, `FAQPage` на главной), метаданные, `sitemap.ts`, `robots.ts`
- интеграцию Larkins: `src/lib/claude.ts` и роут `src/app/api/larkins/route.ts` (Anthropic SDK, сбор брифа из 5 вопросов) — меняется только визуальный слой секции `Larkins` и `LarkinsStage`
- пасхалки в `src/components/easter/` — если ломаются об новые токены, чинить, а не удалять

**Проверить перед сдачей:** `npm run build` и `npm run lint` проходят; обе темы корректны на всех страницах; нет горизонтального скролла на 390px; focus-ring виден везде; при `prefers-reduced-motion` анимации отключены, контент на месте.

## Решения по развилкам (зафиксировано для имплементации)

Позиционирование: сайт должен читаться живым на фоне одинаковых агентских лендингов,
но не отпугивать заказчика. Характер живёт в типографике, ритме и **одном сильном
моменте** (Larkins) — не в эффектах.

| Развилка | Решение |
|---|---|
| Поверхность | Плоская редакционная (`data-surface="web"`). Карточка определяется хайрлайном и воздухом, не тенью |
| Larkins | Гибрид: диалог пузырями слева, справа бриф собирается на глазах. На 390px — одна колонка, панель сворачивается в прогресс-карточку |
| Цвета команды | Один жёлтый акцент. Различие участников — в характеристике, не в оттенке |
| Декоративный слой: оставляем | Бегущая строка направлений, фоновая сетка (единственная текстура), фолио-номер за заголовком, полоса прогресса чтения |
| Декоративный слой: убираем | Шумовой оверлей, кастомный курсор, магнитные кнопки, spotlight по курсору, свечения и градиентные пятна |
| Страницы | Все шесть: главная, `/portfolio`, `/portfolio/[slug]`, `/larkins`, 404, OG 1200×630 |
| Темы в спеках | Обе рядом на каждой карточке |
| Пасхалки: оставляем | Консольная подпись, idle-подсказка в hero, спящий орб на 404 — но орб перерисовать в системе (плоско, без свечения) |
| Пасхалки: убираем | Amber-режим (`[data-mode="amber"]`) — третий набор токенов не окупается |

Первый заход покрывает все восемь блоков выдачи. Если объём придётся резать, приоритет:
токены → типографика → сетка и ритм → примитивы → Larkins → раскладки секций →
движение → список удалённого.

**Отдельная задача по Hero.** После снятия свечений, шума, spotlight и магнитных кнопок
hero остаётся центрированным текстом на почти пустом холсте — правой визуальной части
там нет и не планируется. Нужно 2–3 варианта, чем держать экран **структурно**:
типографический масштаб и разрядка, работа с сеткой и хайрлайнами, композиционный сдвиг
с центра, поведение статистик и бегущей строки как частей композиции, ритм пустоты.
Без маскотов, иллюстраций, орбов и 3D — ограничение из раздела «минимализм — это ДНК»
остаётся в силе.
